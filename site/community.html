The community

Help build the House of Life.

EgyBI grows through cited data and good problems. If you can bring a real dataset about Egypt, a sharp SQL challenge, or a fix — there is a place for you here.

Contribute

Two ways to add to the knowledge base.

A dataset

Bring a cited dataset

Find real, open data about Egypt from a reputable source (World Bank, FAO, CAPMAS, UNESCO, SIPRI, official ministries).
Shape it as a small table — one row per fact, a source_url on every row, and a note that flags anything disputed, approximate or projected.
Propose it as a new seed_vN.sql section plus its schema, and we review it against the accuracy rules before it lands.
A challenge

Write a SQL challenge

Pick a table already in the sandbox and a genuinely useful question (a ranking, a growth rate, a join, a window function).
Write it with a plain-English statement, the givens, a starter query, and a reference solution — the expected output is computed live from the solution.
Add a sourced “Did You Know” so a correct answer teaches something true about Egypt. Then it slots straight into the Practice catalog.
The accuracy rules

Non-negotiable, for everyone.

These are what make EgyBI trustworthy. A contribution that breaks any of them will not be merged.

✓Every fact is real and cited. A source URL on every row — no exceptions, no “roughly” without a source.
✓Disagreement is data. Where reputable sources differ (a rank, a net worth, a religion split), store both and flag it in the note — never smooth it into one tidy number.
✓Original content only. Datasets are public and legally clean; challenges and prose are written from scratch, never copied.
✓Projections are labelled. Targets, forecasts and “by 2030” figures are marked as such, not presented as achieved.
✓Sensitive sectors stay factual. Defence and arms data is limited to published rankings, counts and import statistics from public sources (SIPRI, Global Firepower) — figures only.

Under the hood

The automations that keep it honest.

Pipeline

World Bank refresh

Pulls a curated indicator allowlist, transforms it into cited seed-SQL, and diffs it against the live data so a human approves every change.

Build

Map generator

Rebuilds the offline Egypt-map asset from the boundaries + the latest governorate data whenever a figure changes.

Review

Human-in-the-loop

Automation proposes; a person reviews the diff against the accuracy rules before anything merges. No silent overwrites.

Reach

The Papyrus

A spam-guarded newsletter endpoint appends confirmed subscribers to an append-only store — the one place the site writes.
