The five tallest obelisks

Return the name and height_m of the five tallest obelisks, tallest first.

Solve this challenge →

Runs in your browser. No signup needed.

What you are given

obelisks(name, height_m). Heights are in metres.

Starting point

SELECT name, height_m
FROM obelisks
ORDER BY ...
LIMIT 5;

The reference solution is checked automatically when you run your query on the practice page — results are compared row by row, and order matters for this one.

Did you know

The tallest of all never left the quarry: the Unfinished Obelisk at Aswan cracked while still attached to the bedrock, and would have stood almost 42 m. (Wikipedia, Egyptian obelisks)
