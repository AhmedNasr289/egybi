Born before 1930

Return the name and domain of every cultural figure born before 1930, earliest-born first.

Solve this challenge →

Runs in your browser. No signup needed.

What you are given

Use cultural_figures. Filter birth_year < 1930.

Starting point

SELECT name, domain
FROM cultural_figures
WHERE birth_year < 1930
ORDER BY birth_year;

The reference solution is checked automatically when you run your query on the practice page — results are compared row by row, and order matters for this one.

Did you know

This is the generation of Egypt’s cultural golden age — Umm Kulthum, Mahmoud Mokhtar and Youssef Chahine’s forebears shaped Arab music, art and cinema for the century that followed. (Britannica)
