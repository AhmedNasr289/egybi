What this is, and is not

Where these places come from.

  • This is what OpenStreetMap contains, not an official gazetteer. Places are missing, and the set is denser where the mapping community is more active. Treat it as the geographic pattern of what has been recorded rather than a complete list of Egyptian places.
  • Nothing here is sorted into categories we invented. There is no “oases” or “Red Sea resorts” grouping, because that would be our classification sitting among sourced facts and reading as though it were one. Each place carries only what OSM records.
  • Population is an OSM tag, not a census. It is community-maintained, often years old, and present for only some places. It is shown where it exists and captioned every time.
  • Governorate is computed, not fetched. Each point is tested against the bundled governorate boundaries, so a place just offshore can come back unassigned rather than guessed.
  • No map service is contacted. The outlines ship with the site and the places come from a file in the repository. This page makes zero runtime requests to any tile or map provider.
