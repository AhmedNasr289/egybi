How this page is honest

Method, sources & what this map is not.

Where every layer comes from

Governorate boundaries are geoBoundaries.org (CC-BY 4.0), simplified and bundled into the page so no external map service is ever called. Demographic figures come from the same CAPMAS-sourced knowledge base every SQL challenge on this site queries. Hospitals, clinics and schools come from OpenStreetMap (© OpenStreetMap contributors, ODbL) — a community-maintained map, which means real coverage gaps: these layers show where things are mapped, which is not the same as an official registry of everything that exists. Heritage sites come from the UNESCO World Heritage Centre's public list. Each layer's file records its own fetch date, shown on this page.

What this map is not

This page is informational and educational only. The health layer is not a care directory and says nothing about quality, capacity or opening hours — for real medical needs use official health-ministry channels. Per-governorate counts are assigned using simplified boundaries, so facilities right on a border can be counted one governorate over. Nothing here is advice of any kind. Where a number is a proxy or an undercount, the caption says so instead of hiding it — that's the same cited-data honesty rule the whole site runs on.

Coming next on the Atlas: automated daily layers — earthquakes over Egypt and the Red Sea (USGS) and live air traffic (OpenSky) — built on the same fetch-validate-commit pipelines that already refresh the Prices and FX pages every morning.
