Egypt, on one cited map.

Every layer on this map is real, sourced and dated: Egypt’s 27 governorates (its provinces) coloured by official figures, hospitals and schools as OpenStreetMap volunteers have mapped them, and the seven UNESCO World Heritage sites. It is for exploring, not for finding your way or for emergencies.

Where the map comes from

Method, sources & what this map is not.

Where every layer comes from

Governorate boundaries are geoBoundaries.org (CC-BY 4.0), simplified and bundled into the page so no external map service is ever called. Demographic figures come from the same CAPMAS-sourced knowledge base every SQL challenge on this site queries. Hospitals, clinics and schools come from OpenStreetMap (© OpenStreetMap contributors, ODbL) — a community-maintained map, which means real coverage gaps: these layers show where things are mapped, which is not the same as an official registry of everything that exists. Heritage sites come from the UNESCO World Heritage Centre's public list. Each layer's file records its own fetch date, shown on this page.

What this map is not

This page is for information and learning only. The health layer is not a list of where to get care, and says nothing about quality, capacity or opening hours — if you need medical help, use the official health-ministry channels. Per-governorate counts use simplified boundaries, so a facility right on a border can be counted one governorate over. Nothing here is advice of any kind. Where a number is a stand-in or an undercount, the caption says so — the same cited-data honesty rule the whole site runs on.

Coming next on the Atlas: daily layers that update themselves — earthquakes over Egypt and the Red Sea (USGS) and live air traffic (OpenSky) — the same way the Prices and FX pages already refresh every morning.
